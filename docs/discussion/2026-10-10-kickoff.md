## Decisions
1. **Stack:** PHP 8.4 + MySQL 9.4 via PDO, confirmed installed on the machine. Vanilla JS/CSS, no CDN/build step, so the app runs with just PHP's built-in server.
2. **Persistence via MySQL** (not localStorage) to satisfy "save all data so it stays after refresh" with a real database, per the explicit PHP/MySQL requirement.
3. **Tasks are one shared entity** across the Roadmap and the Kanban board — a task has both a `phase` and a `status`, so checking it done on the roadmap moves it to the Done column and vice-versa.
4. **Phase unlock** is derived (previous phase 100% done), not a stored flag.
5. **Targets:** top-level monthly target fixed at ₹2 Cr / 150,000 students in `settings`; per-vertical targets/actuals editable. Default vertical targets sum to ₹1.98 Cr (near the ₹2 Cr goal).
6. **Docs:** `docs/prompts` holds version-wise prompts, `docs/plan` the implementation plan, `docs/discussion` the narrative. Every future prompt gets a new `vN-*.md`.
